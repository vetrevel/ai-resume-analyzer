# 🚀 AI Resume Analyzer with ATS Optimization

An AI-powered web application that analyzes resumes against job descriptions and provides ATS-based feedback to improve job selection chances.

---

## 📌 Overview

This project helps job seekers optimize their resumes by comparing them with job descriptions using AI. It evaluates resumes based on keyword matching, skills alignment, and ATS (Applicant Tracking System) standards.

---

## 🛠️ Tech Stack

- Frontend: React.js (Vite) + Tailwind CSS  
- Backend: Node.js + Express.js  
- AI Integration: OpenAI API (with fallback support)  
- File Handling: Multer  
- PDF Parsing: pdf-parse  

---

## ⚙️ Features

- 📄 Upload resume in PDF format  
- 📝 Input job description  
- 🤖 AI-based resume analysis  
- 📊 ATS score generation  
- 🔍 Matched skills identification  
- ❌ Missing keywords detection  
- 💡 Suggestions for improvement  
- ⚡ Fast and responsive UI  

---

## 🔄 How It Works

1. User uploads a resume (PDF)
2. User enters job description
3. Backend extracts text from resume
4. AI compares resume with job requirements
5. System returns:
   - ATS Score
   - Matched Skills
   - Missing Keywords
   - Suggestions
